# История изменений проекта AI Chat

## [1.0.0] — 2026-04-16

### Создано
- Первоначальная структура полноценного клиент-серверного чата
- Монорепозиторий с раздельными пакетами `back/` и `front/`
- Единое управление из корневого каталога через скрипты yarn

### Бэкенд (`back/`)
- Настройка Fastify HTTP сервера на порту 3402
- Настройка Socket.io на отдельном порту 3403
- Подключение к PostgreSQL через пул соединений pg
- JWT аутентификация (access токен 1ч, refresh токен 7 дней)
- Маршруты аутентификации: login, logout, refresh, /me
- Маршруты пользователей: CRUD для администратора, смена пароля
- Маршруты бесед: создание личных и групповых чатов, история сообщений
- WebSocket события: сообщения, реакции, статус набора, онлайн-статус
- CORS настройка для фронтенда

### Фронтенд (`front/`)
- React 18 SPA на Vite, порт 3401
- ANT Design 5 — UI компоненты
- RTK Query — REST запросы с автообновлением токенов
- Redux Toolkit — глобальное состояние (auth, chat)
- React Router 6 — маршрутизация с защищёнными роутами
- Socket.io-client — WebSocket соединение
- Страницы: /login, /chat, /users (admin), /settings
- Компонент чата: список бесед + список сообщений
- Реакции emoji на сообщения (emoji-picker-react)
- Ответы на сообщения (цитирование)
- Индикатор набора текста
- Индикатор онлайн-статуса сервера в шапке
- Автоматическое открытие браузера при запуске

### База данных
- Таблицы: users, refresh_tokens, conversations, conversation_members, messages, message_reactions
- Полные COMMENT для всех таблиц, колонок, функций
- Триггеры для автообновления updated_at
- Индексы для оптимизации запросов
- Тестовые пользователи: a@a.ru (admin) и u@u.ru (user), пароль 1234

### Конфигурация
- Раздельные .env файлы для бэкенда и фронтенда
- Примеры .env.example для продакшена
- Все переменные задокументированы комментариями
- Скрипты: yarn dev, yarn build, yarn db:init, yarn stop, yarn clean
