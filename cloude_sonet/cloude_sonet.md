### Причина медленной загрузки

`emoji-picker-react` включает ~900 КБ JSON с данными всех эмодзи + ~1500 SVG/PNG иконок. При синхронном импорте (`import EmojiPicker from 'emoji-picker-react'`) это всё грузится в момент загрузки страницы, а при первом открытии пикера браузер ещё парсит и рендерит весь список.

### Применённые оптимизации

| Приём | Эффект |
|---|---|
| `React.lazy` + `Suspense` | Пикер вынесен в отдельный чанк — не блокирует загрузку страницы |
| `preloadEmojiPicker` при hover | Чанк начинает загружаться когда курсор навёлся на кнопку 😊 — к клику уже готов |
| `lazyLoadEmojis` | Изображения эмодзи подгружаются по мере прокрутки, а не все 1500+ сразу |
| `skinTonesDisabled` | Убирает дополнительные вариации кожи — меньше данных для рендера |
| `manualChunks: { emoji: [...] }` | Vite выделяет пикер в отдельный файл, браузер кэширует его независимо |
| `destroyTooltipOnHide` | Пикер размонтируется при закрытии, освобождает память |
