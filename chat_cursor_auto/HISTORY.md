# История изменений

## 2026-04-17 — Начальная версия

- Исправлена инициализация роли БД: после `DROP DATABASE` выполняется `DROP ROLE IF EXISTS chat_cursor_auto`, затем роль создаётся заново (устранение конфликта при повторном запуске `init_db.sql`).
- Создан каркас монорепозитория: отдельные `package.json` для `front` и `back`, общие скрипты в корне (`yarn dev`, `yarn build`, `yarn db:init`, `yarn clean`, `yarn stop`).
- Реализован бэкенд: Fastify (порт 5102), Socket.IO (порт 5103), PostgreSQL, JWT access/refresh, CRUD пользователей для администратора, беседы (личные и группы), сообщения с ответами, упоминаниями и реакциями.
- Реализован фронтенд: React + Vite (порт 5101, автооткрытие браузера), Ant Design, RTK Query, маршруты `/login`, `/chat`, `/users`, `/settings`, интерфейс чата с боковой панелью и областью сообщений.
- Добавлены SQL-файлы `init_db.sql` и `upd_db.sql` с русскоязычными комментариями к объектам БД.
- Документированы примеры переменных окружения для продакшена (`*.env.production.example`) и рабочие `.env` для локальной разработки.
