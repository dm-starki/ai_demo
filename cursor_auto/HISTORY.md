# История изменений

## 2026-04-16

- Создан каркас монорепозитория: отдельные `package.json` для `back` и `front`, общие скрипты в корне.
- Настроены переменные окружения с комментариями: рабочие `back/.env`, `front/.env` для локальной разработки; примеры для продакшена `back/.env.production.example`, `front/.env.production.example`.
- Реализован бэкенд: Fastify (REST, порт 3102), Socket.IO на отдельном HTTP-порту 3103, JWT access/refresh, роли пользователь/администратор, управление пользователями и беседами, сообщения с ответами, упоминаниями и реакциями.
- Реализован фронтенд: маршруты `/login`, `/chat`, `/users` (админ), `/settings`, фиксированная шапка, индикатор доступности API, чат без скролла страницы (прокрутка только внутри списков), тёмная тема в духе мессенджеров.
- Добавлены SQL-артефакты `back/sql/init_db.sql` и `back/sql/upd_db.sql` с комментариями на русском.
- Скрипт `yarn db:init` выполняет сброс схемы `public` и накат `init_db.sql`, затем создаёт тестовых пользователей с bcrypt-хешем пароля «1234».
